# Specs

One folder per feature, created by the workflow in [`docs/workflow.md`](../workflow.md):

```
docs/specs/<feature>/
├── inception.md          # stage 1
├── breakdown.md          # stage 2: ordered list of slices
└── slice-NN-<name>.md    # stages 2–4: acceptance criteria, grilling log, decisions
```

Start from the templates in [`_templates/`](_templates/).
